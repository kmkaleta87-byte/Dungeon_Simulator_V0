About

This game started as a small coding project to build a basic combat system. It grew as new ideas and systems took shape, and I hope you enjoy exploring it.

The game is open source on GitHub. It includes AI-generated art. Codex helped build the front end and with file management and debugging; I built most of the original C# backend, which is not the version you are playing. I am learning HTML and CSS as I continue working on the browser game.

Feedback is welcome at kmkaleta87@gmail.com. Thanks for playing!
